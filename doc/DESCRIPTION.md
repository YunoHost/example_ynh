FediMod FIRES (Fediverse Intelligence Recommendations Replication Endpoint Server) is a server for sharing and replicating moderation recommendations and threat intelligence between fediverse servers.

It lets moderators publish, subscribe to and replicate curated datasets (such as domain blocks and advisories) so that fediverse operators can coordinate moderation decisions across instances.

This package deploys the FIRES reference server (an AdonisJS / Node.js application backed by PostgreSQL).
